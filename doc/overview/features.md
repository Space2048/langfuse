# Langfuse 核心特性

Langfuse 提供了一套完整的 LLM 工程工具集，涵盖开发、监控、评估和调试的全流程。

## 🔍 LLM 应用可观测性

### 实时追踪
- **端到端追踪**：追踪完整的 LLM 调用链
- **多层级观测**：Trace → Span → Generation 层级结构
- **实时可视化**：实时的调用链可视化界面
- **性能指标**：延迟、成本、令牌使用等指标

### 调试工具
- **交互式调试**：直接在界面中调试和重放调用
- **差异对比**：对比不同版本的提示和结果
- **错误分析**：自动识别和分类错误模式
- **上下文查看**：完整的输入输出上下文

## 📝 提示管理

### 集中化管理
- **版本控制**：提示的完整版本历史
- **协作编辑**：团队协作编辑和评审
- **环境管理**：开发、测试、生产环境分离
- **标签系统**：灵活的标签和分类系统

### 优化功能
- **A/B 测试**：并行测试不同提示版本
- **性能分析**：提示性能和成本分析
- **自动优化**：基于历史数据的提示优化建议
- **缓存策略**：智能缓存减少延迟和成本

## 📊 评估系统

### 评估框架
- **LLM 作为裁判**：使用 LLM 自动评估结果
- **人工评估**：团队协作的人工评估流程
- **自定义评估**：支持自定义评估指标和逻辑
- **批量评估**：大规模数据集的批量评估

### 数据集管理
- **测试数据集**：创建和管理测试数据集
- **版本控制**：数据集的版本管理
- **导入导出**：多种格式的数据导入导出
- **基准测试**：建立和维护性能基准

## 🎮 LLM 试玩平台

### 交互式测试
- **实时测试**：直接在界面中测试提示
- **多模型支持**：支持多种 LLM 提供商
- **参数调整**：实时调整模型参数
- **历史记录**：测试历史记录和比较

### 集成开发
- **代码生成**：从测试生成集成代码
- **配置导出**：导出完整的配置供生产使用
- **团队共享**：共享测试结果和配置
- **快速迭代**：缩短开发反馈循环
