# Langfuse 项目介绍

## 什么是 Langfuse？

Langfuse 是一个 **开源 LLM 工程平台**，帮助团队协作 **开发、监控、评估** 以及 **调试** AI 应用程序。Langfuse 可在几分钟内 **自托管**，并且经过 **实战考验**。

## 🎯 项目愿景

Langfuse 旨在成为 LLM 应用开发的标准工具，提供：

1. **完整的可观测性** - 追踪 LLM 调用和应用逻辑
2. **协作式开发** - 团队协作管理提示和评估
3. **生产就绪** - 支持大规模部署和自托管
4. **开发者友好** - 提供丰富的 SDK 和 API

## 🏢 项目背景

Langfuse 由经验丰富的 AI 工程师和 DevOps 专家创建，旨在解决 LLM 应用开发中的常见痛点：

1. **调试困难** - LLM 调用难以追踪和调试
2. **协作障碍** - 提示和配置难以共享和版本控制
3. **评估复杂** - 缺乏标准化的评估流程
4. **运维挑战** - 生产环境监控和告警不足

## 🌍 生态系统

### 核心组件
1. **Web 应用** - Next.js 14 全栈应用
2. **Worker 服务** - Express.js 后台处理
3. **共享包** - 类型定义和工具函数

### 集成 SDK
- **Python SDK** - 完整的 Python 集成
- **JavaScript/TypeScript SDK** - 前端和后端集成
- **OpenAI 集成** - 自动追踪 OpenAI 调用
- **LangChain 集成** - 无缝的 LangChain 支持

### 数据存储
- **PostgreSQL** - 事务性数据存储
- **ClickHouse** - 分析性数据存储
- **Redis** - 缓存和队列
- **S3/MinIO** - 对象存储
