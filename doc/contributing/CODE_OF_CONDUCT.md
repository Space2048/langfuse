# 贡献者行为准则

## 我们的承诺

为了营造一个开放、友善的环境，我们作为贡献者和维护者承诺：无论年龄、体型、身体健全与否、民族、性征、性别认同与表达、经验水平、教育程度、社会与经济地位、国籍、相貌、种族、宗教信仰、性取向，我们都要以友善的态度对待项目社区中的每一个人。

## 我们的准则

有助于创造积极环境的行为包括但不限于：

* 使用友善和包容性语言
* 尊重不同的观点和经历
* 耐心接受有益批评
* 关注对社区最有利的事情
* 友善对待其他社区成员

不能容忍的行为包括但不限于：

* 使用与性有关的言语或是图像，以及不受欢迎的性骚扰
* 挑衅、侮辱/贬损的评论，及人身攻击或政治攻击
* 公开或私下的骚扰
* 未经明确授权便发布他人的资料，如地址、电子邮箱等
* 其他有理由认定为违反职业操守的不当行为

## 我们的责任

项目维护者有责任为「可接受的行为」标准做出表率，并公正、适当地对已发生的不当行为采取纠正措施。

项目维护者有权利和义务去删除、编辑、拒绝违背本行为准则的评论（comments）、提交（commits）、代码、wiki 编辑、问题（issues）和其他贡献，以及临时或永久地封禁任何他们认为行为不当、威胁、冒犯、有害的贡献者。

## 适用范围

本行为准则适用于项目空间和公共空间。当个人代表项目或其社区时，本行为准则同样适用。代表项目或社区的情形包括但不限于：使用项目的官方电子邮件地址、通过官方社交媒体账号发布消息、作为指定代表参与在线或线下活动等。代表项目的行为可由项目维护者进一步定义和解释。

## 强制执行

可以通过 [support@langfuse.com](mailto:support@langfuse.com) 联系项目团队来举报滥用、骚扰或其他不可接受的行为。所有投诉都会得到及时、公正的审查和调查。

项目团队有义务对事件的举报者予以保密。具体执行政策的更多细节可能会单独发布。

没有切实遵守行为准则的项目维护者可能会因项目领导层的决定而暂时或永久地剥夺参与项目的资格。

## 执行指南

### 1. 纠正措施

当项目维护者认定某行为违反了本行为准则时，他们将采取他们认为适当的纠正措施。纠正措施可能包括：

1. **口头警告**: 私下沟通，解释行为不可接受的原因
2. **公开警告**: 在相关讨论中公开指出行为问题
3. **临时封禁**: 暂时禁止参与项目讨论或贡献
4. **永久封禁**: 永久禁止参与项目

### 2. 举报流程

如果您是骚扰或不当行为的受害者，或者注意到此类行为，请：

1. **收集证据**: 保存相关消息、评论或行为的截图
2. **联系维护者**: 发送邮件至 [support@langfuse.com](mailto:support@langfuse.com)
3. **提供细节**: 包括时间、地点、涉及人员和具体行为
4. **保持冷静**: 避免在公开渠道升级冲突

### 3. 冲突解决

对于贡献者之间的分歧和冲突，我们鼓励：

1. **私下沟通**: 首先尝试私下解决分歧
2. **寻求调解**: 如果无法解决，请求项目维护者调解
3. **尊重决定**: 接受项目维护者的最终决定

### 4. 申诉流程

如果您对处理结果不满意，可以：

1. **请求复审**: 向项目领导层请求复审决定
2. **提供新证据**: 提供之前未考虑的证据
3. **接受最终决定**: 项目领导层的决定是最终决定

## 社区期望

### 积极行为
- **建设性批评**: 专注于改进建议，而非人身攻击
- **包容性语言**: 使用中性语言，避免假设他人背景
- **耐心指导**: 帮助新贡献者学习和成长
- **尊重时间**: 在他人在线时及时响应，离线时耐心等待

### 沟通准则
- **清晰表达**: 使用明确、具体的语言
- **倾听理解**: 在回应前确保理解对方观点
- **保持专业**: 即使意见分歧，也保持专业态度
- **及时道歉**: 如果无意中冒犯他人，及时道歉

### 技术讨论
- **事实为基础**: 基于技术事实进行讨论
- **尊重专业知识**: 承认不同领域的专业知识
- **开放心态**: 愿意学习和接受新方法
- **文档优先**: 重要决策和讨论应有文档记录

## 特殊情况

### 安全漏洞
- **私下报告**: 安全漏洞应私下报告至 [security@langfuse.com](mailto:security@langfuse.com)
- **禁止公开**: 在修复前不得公开讨论安全漏洞
- **协调披露**: 遵循负责任的披露流程

### 法律问题
- **尊重法律**: 所有贡献必须遵守适用法律
- **知识产权**: 尊重他人知识产权
- **数据隐私**: 保护用户隐私和数据安全

### 商业利益
- **透明披露**: 如有商业利益相关，应透明披露
- **公平竞争**: 避免利用项目进行不公平竞争
- **社区优先**: 社区利益优先于商业利益

## 持续改进

本行为准则不是一成不变的。我们将：

1. **定期审查**: 每年至少审查一次行为准则
2. **社区反馈**: 征求社区成员对行为准则的反馈
3. **更新完善**: 根据经验和反馈更新行为准则
4. **透明变更**: 所有变更都将透明地进行
